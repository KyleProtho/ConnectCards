# Connect Cards

A modern, interactive conversation starter app designed to help people connect through meaningful questions. Choose from curated question decks, select how many questions you'd like, and dive into engaging conversations.

## 🌐 Live Demo

**[Try Connect Cards on GitHub Pages →](https://kyleprotho.github.io/ConnectCards/)**

## About

Connect Cards helps facilitate deeper connections through carefully crafted conversation prompts. Whether you're looking to strengthen relationships, break the ice with new people, or simply have meaningful conversations, Connect Cards provides the perfect starting point.

### Features

- **Multiple Question Decks**: Choose from various categories including dating, getting to know strangers, and more
- **Customizable Experience**: Select the number of questions you want (1-50)
- **Clean, Modern Interface**: Built with React and styled with Tailwind CSS
- **Mobile-Friendly**: Responsive design that works seamlessly on all devices
- **Shuffled Questions**: Questions are randomly shuffled each time for a fresh experience

## Tech Stack

- **React 19** - Modern UI framework
- **TypeScript** - Type-safe development
- **Vite** - Fast build tool and dev server
- **Tailwind CSS** - Utility-first CSS framework

## Getting Started

### Prerequisites

- Node.js 20 or higher
- npm

### Installation

1. Clone the repository:
```bash
git clone https://github.com/KyleProtho/ConnectCards.git
cd ConnectCards
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser to `http://localhost:3000`

### Building for Production

```bash
npm run build
```

The built files will be in the `dist/` directory.

## Deployment

This project is automatically deployed to GitHub Pages on every push to the `main` branch using GitHub Actions. The workflow builds the project and deploys it to `https://kyleprotho.github.io/ConnectCards/`.
